# Projeto Exemplo - Página Web Pessoal

Este é o projeto inicial criado para praticar versionamento com Git e GitHub.

##  Funcionalidades

- Página inicial com informações básicas.
- Estilização com CSS.

##  Estrutura de Arquivos

- `index.html` – Estrutura principal da página.
- `style.css` – Estilos visuais.

##  Como executar

Basta abrir o arquivo `index.html` em qualquer navegador.

##  Versionamento

- **1.0** – Estrutura inicial.
- **1.1** – Adição de parágrafo sobre aprendizado de Git.
