##  Boas Práticas de Segurança e Governança (Validado com IA Gemini)

Em conformidade com os requisitos de Engenharia de Software e com o apoio consultivo do Google Gemini, este repositório adota as seguintes práticas de segurança:
- **Princípio do Menor Privilégio (PoLP):** O controle de acesso ao repositório é restrito estritamente ao proprietário para commits diretos na branch `main`.
- **Prevenção de Vazamento de Credenciais (Secret Scanning):** Monitoramento ativo para garantir que nenhuma chave de API, senhas ou arquivos de configuração privada (como arquivos `.env`) sejam comitados.
- **Segurança de Dependências:** Ativação do *GitHub Dependabot* para análise e correção automatizada de vulnerabilidades em pacotes e links estruturais.
